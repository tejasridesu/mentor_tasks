
Problem
 
The disk usage has reached 95%.
 
Commands Used
 
df -h
du -sh /*
du -sh /var/*
 
Steps
 
1. Run "df -h" to confirm disk usage.
2. Find which folder is using the most space using "du -sh /*".
3. Investigate inside that folder.
4. Find large files or directories.
5. Clean unnecessary files safely.
6. Check disk usage again.
 
 
Solution
 
Identify the large directory or files, remove unnecessary data safely, and verify that disk usage has decreased.
